## 更新约定

- 刷题记录包含：难度、自主完成情况、核心思路、复杂度和代码。
- 八股笔记优先记录自己的理解，并补充追问和容易混淆的知识点。
- 投递信息中的手机号、邮箱、候选人编号等隐私内容不提交到公开仓库。
- 面试复盘使用匿名公司代号；如需公开公司名称，会先移除敏感信息。
